# 2026-06-15 — 차량관리 요일별 시간 덮어쓰기 버그 수정 + PWA 설치 지원

## 1) 버그: 요일별 다른 호차 학생의 시간이 덮어써짐 (조준우 유치부 하원)

### 증상
한 학생이 요일별로 다른 호차를 탈 때(수=2호차/15:03, 월·금=5호차/15:22),
2호차(수) 15:03 저장 후 5호차(월·금) 15:22를 저장하면 다시 수요일을 보면
2호차 시간이 나중에 입력한 **15:22로 바뀌어 있음**.

### 근본 원인 (`app/api/campus/vehicles/route.ts` `update_enrollment_schedule`)
- 스케줄 JSON은 시간을 **공유 `_time` 하나** XOR **요일별 `{요일}_time`** 중 하나로만 저장하는 불변식
  (차량관리는 `_time`, 개설반 현황 StudentDetailModal은 요일별 시간을 우선 읽음 → 섞이면 화면 시간 어긋남).
- 단일 모드 저장이 무조건 `sched['_time'] = pickup_time` + `clearPerDayTimes()`(모든 요일별 시간 삭제)를 수행.
- 한 enrollment가 여러 호차로 나뉘면, 한쪽 호차 저장 시 공유 `_time`이 그 시간으로 통일되고
  다른 요일(수)의 시간이 사라짐. 읽을 때 `_time`이 요일별보다 우선이라 수요일이 15:22로 표시.

### 수정
- `lib/utils/vehicle-schedule.ts`: 스케줄 변형 로직을 순수 함수 `applyEnrollmentSchedule()`로 추출.
  **dayList 밖에 다른 호차 배정이 남아있으면** 기존 공유 `_time`을 그 요일들의 요일별 `_time`으로 먼저
  이관 → 편집 요일만 요일별 `_time`으로 적용 + 공유 `_time` 제거(요일별 모드 전환). 단일 호차 전 요일
  케이스는 기존대로 공유 `_time` 유지. "_time XOR 요일별" 불변식 보존. day_times 경로의 동일 잠재버그도 해결.
- `app/api/campus/vehicles/route.ts`: 인라인 로직 → 위 함수 호출로 교체.
- 회귀 테스트 4개 추가(`tests/vehicle-schedule.test.ts`): 정/역순 저장·day_times 경로 모두 수요일 15:03 보존 확인.

## 2) PWA 설치 지원 (링크 공유 → 받아서 설치 → Poly 앱)

### 배경
바탕화면 .lnk 바로가기는 PC 경로가 박혀 카톡 공유 시 깨짐(폰에선 무동작). → URL 공유가 정답이나,
설치 시 기본 아이콘/이름이 떠 밋밋. PWA 매니페스트로 Poly 아이콘 + "Poly 시스템" 이름 자동 적용.

### 변경
- 아이콘 생성(`public/poly-emblem.png` 기반, Royal Blue #004EA2 라운드/풀블리드):
  `public/icons/poly-any-{192,512}.png`(라운드·투명, purpose any), `poly-maskable-{192,512}.png`(풀블리드, maskable),
  `app/icon.png`(512), `app/apple-icon.png`(180 풀블리드, iOS 라운드).
- `app/manifest.ts`: name "Poly 시스템"/short "Poly"/standalone/theme `#004EA2`/icons.
- `app/layout.tsx`: `metadata.manifest`, `appleWebApp.title='Poly 시스템'`, `viewport.themeColor='#004EA2'`.
- **`proxy.ts` 매처에 `webmanifest` 제외 추가** — 안 하면 `/manifest.webmanifest`가 인증 미들웨어에
  걸려 `/login`으로 307 리다이렉트 → PWA 설치 깨짐. (Next 16: middleware = `proxy.ts`)

### 사용법(공유)
링크 `https://poly-system.vercel.app` 전송 → PC: 주소창 설치 아이콘(⊕) / 폰: 브라우저 "홈 화면에 추가".
