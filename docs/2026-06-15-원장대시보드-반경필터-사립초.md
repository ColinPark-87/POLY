# 2026-06-15 원장 대시보드 반경필터 정리 (중계/정발/대치 제외 9개 캠퍼스)

## 요청
중계처럼 나머지 캠퍼스 원장 대시보드 채우기. 가)중계 읽기전용 나)동/아파트/학교 좌표는 캠퍼스 주소 반경 15km 이내만
다)상위 학교/아파트 중계처럼 정리 라)사립초 검색확인+반경15km 분류 마)중계·정발·대치 제외 바)백업선행.
+ 후속: 광교·광명은 반경 줄여 겹침 방지(센터 24km 이격 → 11km).

## 진단
- 대시보드(`app/(campus)/campus/dashboard/page.tsx`)는 campus_students(school/apartment/grade/...)에서 상위 학교/아파트·사립초 집계.
- ⚠️**데이터 오염**: 광명 학생의 약 52%(241/466)가 광교(수원) 학생. 광명 상위학교에 수원 학교(신풍/산의/광교/매원/광교호수)가 뜸 → 반경필터의 핵심 이유.

## 구현 (코드+생성데이터, DB 미변경)
1. **반경필터 생성기** `scripts/gen-campus-geo-filter.mjs`: 캠퍼스 중심좌표 기준 학교/아파트를 중심편향 지오코딩 → 반경 내만 표시. 반경 광교·광명=11km, 그 외 15km. 결과 `lib/data/campus-geo-filter.json`(캠퍼스별 schools/apartments + within).
2. **analytics route** `/api/campus/analytics`: 캠퍼스명으로 JSON 조회 → `geoFilter{radiusKm, schoolsInRegion, aptsInRegion}` 반환. (JSON에 없는 캠퍼스=중계/정발/대치는 geoFilter null → 기존 동작 유지)
3. **dashboard**: `processDb(students, geoSets)`에서 아파트명 normalizeApt + **반경 밖 학교→'없음'·아파트→'기타'** 처리(기존 '없음'/'기타' 필터가 랭킹·사립초에서 자동 제외). 사립초 분모는 반경필터 캠퍼스 한정 '학교 아는 초등학생'으로.
4. **사립초 명단 확장** `PRIVATE_SCHOOLS`: 수원(소화·중앙기독·수원중앙기독·용인한얼)·대전(삼육·성모·목양)·목동/강남(이대부속·홍대부속·리라·경기·경복)·송도(박문·인천박문·인성·영화) 추가. ⚠️검색기반 분류라 **담당자 검수 권장**.
