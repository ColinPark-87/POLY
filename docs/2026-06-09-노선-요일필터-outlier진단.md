전날(2026-06-08) `docs/2026-06-08-차량노선정리-내일할일.md`의 "내일 할 일 2가지"를 순서대로 처리한 기록.

## 작업 1) 노선 페이지(Page1) 요일 필터 추가 — ✅ 완료

### 배경
- 노선이 지저분해 보이는 잔여 원인 = 같은 정류장에 **늦은 시간 1~2명**이 섞여, 시간순 노선이 그 정류장으로 되돌아옴.
- 실제로는 그 시간이 **특정 요일만 다른 일정**인 경우가 많음(아래 진단 참고). 주간 합집합으로 보면 한 정류장에 여러 시간이 겹쳐 노선이 꼬임.
- → 호차 명단 카드의 요일 토글(`rosterDay`) 패턴을 노선 페이지에도 적용해, **선택 요일에 타는 학생만**으로 노선을 그리면 하루치 동선만 깔끔하게 보임.

### 변경 (`app/(campus)/campus/vehicles/RouteMapView.tsx`)
- `routeDay` 상태 신설(`''`=주간 전체, 아니면 월~금). 진입 시 오늘 요일 자동 선택(rosterDay와 동일 effect).
- `routeStopsByBus` useMemo: 요일별 펼침 루프에서 `if (routeDay && day !== routeDay) continue` → 선택 요일에 타는 정류장만 집계. 빈 정류장 마스터(학생 0명) 합집합은 요일 필터 시 제외(`if (!routeDay)`)해 그날 타는 정류장만 노출. dep에 `routeDay` 추가.
- `bothDirStopsByBus`(등하원 같이보기)에도 동일 필터 + dep에 `routeDay` 추가.
- Page1 패널 호차 섹션 아래에 요일 토글 UI(월~금 + 전체, `DAY_DOT_COLOR` 재사용). 헤더에 "{요일}요일 노선 / 주간 전체" 표시.
- 지도/TMAP 노선은 `routeStopsByBus`에 의존하므로 요일 변경 시 자동 재계산·재그리기.
- '전체' 선택 시 동작은 기존과 동일(주간 합집합) → 회귀 없음.

## 작업 2) 늦은-시간 outlier 정리 — 🟡 진단만(사용자 결정: 데이터 통일 보류)

### 진단 (읽기전용)
- 스크립트: `scripts/diag-time-outliers.mjs` (서비스키는 `.env.local`에서 로드, 페이지네이션, 현재 달만).
- 같은 **(캠퍼스·방향·호차·정류장·세션라벨)** 안에서 대표시간(최빈) ±15~90분 벗어난 학생 추출.
  - 세션라벨로 묶는 게 핵심: 같은 정류장이라도 유치부 아침등원 vs 초등부 오후등원처럼 **세션이 다르면 시간이 당연히 다름**(노선은 세션 단위로 그려짐).
- 결과: 15개 (호차·정류장) 그룹. `scripts/_out/time-outliers.json`에 저장.

### 핵심 관찰
- outlier 다수가 **"특정 요일만 다른 시간"**(예: 권래아·노아준 = 수요일만 16:40 / 평소 15:22, 조준우·조윤아 = 수요일만 15:30 / 평소 15:03).
  → 오타가 아니라 **그 요일 실제 일정**일 가능성이 높음. 일괄 통일하면 안 됨.
  → 그리고 이런 케이스는 **작업 1의 요일 필터로 이미 해결**(요일별로 보면 안 섞임).
- 단일 오타 의심(대표시간 뚜렷+소수 이탈): 신안동진 김도율 금 15:30, 정발 임도윤 19:48(+60 시 오타 의심) 등.
- 분산 큼(단일 대표시간 불명확): 중계 3호차 어린이집/양지대림, 중계 7호차 건영3차 윤슬아 16:50(-87).

### 결정
- **데이터 통일은 보류**(사용자 결정). 진단 JSON 보관 → 추후 재개 시 바로 사용.
