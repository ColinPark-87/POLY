# 2026-06-15 차량지도 — 좌표 없는 캠퍼스가 중계로 당겨지는 문제

## 요청
캠퍼스별 차량관리 지도를 열면 본인 캠퍼스가 중심이어야 하는데 일부가 중계로 당겨짐. 전체 점검.

## 진단 (READ-ONLY, 전 캠퍼스)
- 지도는 초기 생성 시 **하드코딩 중계 좌표(37.6556,127.0686)** 로 center. 이후 센터링 effect가
  `coords[캠퍼스명]`(학원좌표) → 정류장 bounds → 단일좌표 순으로 이동. **좌표가 0개면 아무것도 안 해
  초기 중계 중심에 그대로 묶임.**
- 전 캠퍼스 점검: **광교·분당이 좌표 0개 → 중계로 당겨짐.** 나머지(광명·대전·대치·목동·송도·송파·수지·운정·정발·중계)는
  학원좌표 또는 충분한 정류장이 있어 정상. (운정은 앞선 작업에서 센터 1행 추가로 이미 정상.)

## 수정 (코드 전용 — DB 미기록)
`RouteMapView.tsx` 센터링 effect에 **3순위 폴백** 추가: 좌표 0개 캠퍼스는 `/api/geocode?q=폴리어학원 {캠퍼스명}`
로 학원 위치를 지오코딩해 그 지점으로 center. 결과는 `localStorage academy-center-{campusId}` 에 캐시(반복 Kakao 호출 방지),
`academyGeoRef`로 1회 가드, `coordsDbLoadedKey===coordsKey`(DB 로드 완료) 후에만 실행(로드 중 빈 좌표 오발동 방지).
→ 광교·분당 및 **향후 좌표 없는 신규 캠퍼스도 자동으로 본인 지역 중심**. 중계 데이터·DB 미변경.

지오코딩 신뢰성 확인(READ-ONLY): '폴리어학원 광교'→폴리어학원 광교캠퍼스(수원 영통 에듀타운로102),
'폴리어학원 분당'→폴리어학원 분당캠퍼스(성남 분당 성남대로349). 정확.

## 검증
`npm run build` 통과. 좌표 있는 캠퍼스는 기존 로직 그대로(폴백 미발동).

## 참고 (선택)
폴백은 지도 중심만 잡고 '학원 핀 마커'(coords[캠퍼스명])는 생성하지 않음. 광교·분당에 **영구 학원좌표 1행**
(`campus_stop_coords` stop_name=캠퍼스명)을 넣으면 핀 표시+UI 편집까지 가능(검증된 학원좌표 보유). DB 쓰기라 사용자 승인 후 진행.
