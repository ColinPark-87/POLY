# 2026-06-15 초등부 히어로 분류 = "유치부 외 전부 초등부"

## 증상
송도 캠퍼스 roster 히어로(통계 바)에서 **초등부가 안 뜸**. 송도는 ECP=유치부, 나머지 전부 ELE(초등부).

## 원인
roster 히어로의 초등부 합계가 **세션명 키워드(매일반/월수금/화목/3일/2일)** 매칭의 합으로 계산됨:
```
초등부Total = 매일반Total + 삼일반Total + 이일반Total
```
송도 ELE 세션명(`ELE 1st Block`, `ELE 2nd Block(TTH)`, `2nd Block(MWF)`, `2nd Block`)은
이 키워드들과 안 맞아 셋 다 0 → 초등부Total=0 → `{초등부Total > 0 && ...}`로 칩 숨김 + 수강 합계도 과소.
(HQ **전체** 대시보드 히어로는 `getCategory`로 "유치부 외 전부 초등부"라 이미 정상이었음 — 문제는 **per-campus** 뷰.)

## 수정 — "유치부·방과후 아닌 전부 = 초등부"
세 군데의 초등부 계산을 catch-all로 변경 (매일반/3일반/2일반 세부 칩은 표시용으로 유지):
- `components/HqRosterView.tsx` (HQ 읽기전용 캠퍼스 뷰): `초등부Total = getSessCount(n => !유치부 && !방과후)`
- `app/(campus)/campus/class-roster/page.tsx` 메인 카운트: `_초등부 = _getSessCount(n => !유치부 && !방과후)`, `grandSessTotal = _유치부 + _초등부`
- 동 RosterTab 통계 바: `초등부SessTotal = getSessCount(n => !유치부 && !방과후)`
