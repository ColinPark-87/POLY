# 2026-06-15 개설반 현황 — 세션 반 12개 초과 시 2줄 정렬

## 요청
개설반 현황에서 한 세션의 반 개수가 12개를 넘으면 반으로 나눠 2줄로 정렬.

## 수정
`app/(campus)/campus/class-roster/page.tsx` RosterTab 세션 카드 영역:
- `visibleClasses.length > 12` 이면 `classRows = [앞 ceil(n/2), 뒤 나머지]` 두 줄로 분할(이하면 1줄).
- 카드 컨테이너를 `classRows.map(rowClasses => <flex row>)`로 감싸고, 각 줄의 카드폭(`rowCardWidth`)을
  그 줄의 반 개수 기준으로 계산해 각 줄이 가로폭을 꽉 채우게 함. 줄 간격 `space-y-1.5`.
- 분할은 **표시(렌더)만** — 내부 `sessClasses` 배열은 그대로라 카드 드래그 순서변경·학생 드래그 정상.

## 검증
`npm run build` 통과. 12개 이하 세션은 기존과 동일(1줄), 13개↑는 2줄.
