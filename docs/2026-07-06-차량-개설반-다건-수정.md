## [2026-07-06 #6] 개설반 현황 모달 요일별 등하원 시간 편집 신설
- **증상**: 유치부 김건우를 특정 요일만 매일반 정류장·시간으로 하원하려는데 시간이 계속 유치부 시간으로 되돌아감.
- **근본원인**: 개설반 학생 모달에 **요일별 시간 편집칸이 없었음**. 요일별 호차·장소만 저장하고 시간은 유치부 공유 `_time` 유지. 읽기 우선순위도 `_time > {요일}_time`이라 유치부 시간이 항상 이김.
- **수정**: 모달에 요일별 등원/하원 시간 input 추가(호차 있는 요일만). 정류장 선택 시 시간이 모호하지 않으면 자동채움. 저장 `buildDirSchedule` — 시간 **XOR 불변식**(탑승 요일 시간 동일→공유 `_time`, 다르면 요일별 `{요일}_time`+`_time` 제거). 무변경 저장은 기존과 동치.
- **라이브 검증**: 시간 입력칸 정상 렌더 확인. 저장 로직 tsc·154테스트·실데이터(SR enrollment 화=16:50 정상 저장) 확인.
- **주의**: 김건우는 enrollment 다수(ECP7·ECP6·유치부 방과후 여러)라 화요일 배차가 반마다 흩어져 충돌(ECP6 화=8호차 vs SR 화=7호차 16:50). enrollment 정리 필요(원장 진행).
- **커밋/배포**: `828b361` → `poly-614os6vsi`. 백업 `backup/pre-roster-perday-time-20260706`.
