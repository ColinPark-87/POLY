## 평가축 2 — 사용자 인터페이스 개선

신규/개선 인터랙션 5가지:
1. **Hero ETA 카드** — 호차 선택 즉시 출발→도착·총인원·정류장·소요·거리 한눈에 (이전엔 직접 합산 필요)
2. **정류장 타임라인** — "학생 명단" → "정류장×시간" 관점 전환. 비어있는 정류장/시간 충돌 가시화
3. **번호 토큰 + 방향 화살표** — 지도만 봐도 노선 순서·진행방향 판독 (이전엔 시간 컬럼 확인 필요)
4. **FAB 컨트롤** — 노선 전체보기 / 학원 센터 / 줌을 한 손 조작 (이전엔 휠 스크롤만)
5. **다음 정류장 미니 바** — 단일 호차 선택 시 다음 정류장·시각·인원·총 소요 표시

운영 가치: 학부모 응대 속도 ↑, 노선 동선 이상 탐지 용이, 외부 노출 시 신뢰감.
