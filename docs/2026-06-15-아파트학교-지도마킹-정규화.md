# 2026-06-15 차량지도 학교/아파트 마킹 — 중계처럼 정규화 (광명·수지·송도·송파·운정)

## 요청
중계 차량관리 지도를 참조(읽기전용)로, 광명·수지·송도·송파·운정 학생 명부의 아파트/학교가
중계처럼 지도에 마킹되도록 설정. 중계는 읽기 전용(데이터 변경 금지).

## 진단 (READ-ONLY)
- 데이터는 이미 채워짐: 아파트 채움 광명690/수지577/송도400/송파477/운정271, 학교도 상당수.
- 마킹 메커니즘: `RouteMapView`가 캠퍼스 센터(`campus_stop_coords` 중 캠퍼스명과 같은 stop) 기준
  반경 5km로 학교/아파트명을 Kakao 지오코딩(`/api/geocode`) → 버블. **센터 없으면 `if(!center) return`로 지오코딩 자체 안 함.**
- 벤치마크 중계: 상위5 아파트 5/5 성공(클린 단지명). 반면 대상 캠퍼스는:
  - **운정**: 센터 좌표 자체가 없음 → 마킹 0.
  - 광명·수지: 1/5 (띄어쓰기 변형 `이편한세상 수지`/`이편한 세상 수지`, 동-호수 `112-1503`, 잡음 `★ 차`).
  - 송도 4/5, 송파 3/5.

## 수정 (코드 정규화 — 데이터 대량변경 없이)
1. `lib/utils/apartment-name.ts` 신설: `normalizeApt`(공백정규화·★☆ 잡음제거·끝의 동/호수 제거),
   `aptMatchKey`(공백무시 키), `aptNameMatches`(공백무시 포함매칭).
2. `app/api/campus/students/route.ts` 집계: `apartments=1`은 `normalizeApt`로 묶어 클린 단지명+합산 카운트,
   `schools=1`은 공백정규화. (소비처는 RouteMapView 뿐 — 확인)
3. `RouteMapView.tsx` 지오코딩 매칭: `aptNameMatches`(공백·표기차 무시) → 없으면 **같은 종류 폴백**
   (아파트는 `/아파트|단지/`, 학교는 `/학교|초등|중학교|고등학교/` 인 결과로만) → 카페·부동산 오마킹 방지.
   스팟 캐시키 v3→v4(클라 재지오코딩 강제).
