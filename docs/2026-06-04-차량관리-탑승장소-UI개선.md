# 차량관리 · 탑승장소설정 UI 개선 (2026-06-04)

> 대상: `/campus/vehicles` — `app/(campus)/campus/vehicles/RouteMapView.tsx` (단일 파일)
> 배포: Vercel CLI 직접 (`npx vercel --prod`) → https://poly-system.vercel.app
> 검증: 각 단계 `tsc --noEmit` 0 · `next build` 0 · 배포 READY

이날 작업은 차량관리 지도 우측 "리모컨"의 **탑승장소설정** 화면과 지도 **학교/아파트 스팟**을 사용성 위주로 개선한 묶음이다. 데이터·API·권한 로직은 변경하지 않았다.

---

## 1. 탑승장소설정 정류장 목록 정렬

- **문제**: `전체`·`미설정` 목록이 가나다순도 호차순도 아닌 임의 순서. 원인은 `allStops`가 `Map` 삽입 순서(enrollment 데이터 적재 순)를 그대로 반환하고, 렌더 시에도 정렬이 없었음.
- **수정**: `allStops` 단일 소스에 `.sort((a, b) => a.name.localeCompare(b.name, 'ko'))` 추가 → 전체·미설정·검색·호차별 모두 한글 가나다순.

## 2. 정류장 수정 = 드래그 이동 가능한 팝업

- **의도**: 정류장을 클릭하면 그 정류장의 수정정보가 **별도 팝업**으로 뜨고, 팝업을 **드래그로 이동**할 수 있어야 함.
- **구현**: 목록 행/학원좌표 클릭(`openStop` → `expandedStop`) 시 `renderStopExpanded`를 최상위 `fixed` 팝업으로 표시. 헤더(⠿⠿ + 정류장명)를 드래그 핸들로(`startStopCardDrag`/`stopCardPos`, 기존 addStopCard 패턴 재사용), `×`로 닫기.
- 기존 인라인 펼침(목록 행 아래 / 학원좌표 블록) 2곳 제거.
- z-index: 정류장추가·탑승자추가 모달(z-9001+)이 이 팝업(z-8000) 위에 정상 노출.
- (이전 시도였던 "탭 전체를 중앙 모달로" 방식은 의도와 달라 전부 revert 후 위 방식으로 재구현.)

## 3. 수정 중 정류장 위치 강조 마커

- **문제**: 수정 팝업이 떠도 지도에서 그 정류장이 **어디인지** 안 보임.
- **구현**: `sidebarPage === 4 && expandedStop`일 때 해당 좌표에 **빨간 펄스 핀 + "수정 중" 라벨** CustomOverlay 표시(`stopEditHlRef`, z250). 검색결과 클릭용 임시 하이라이트(`highlightMarkerRef`, 3초)와는 **별도 ref**로 분리.

## 4. 학교/아파트 스팟 개선

- **`여기로`·`숨김` 버튼 제거**: 관리 패널(`spotManage`)의 두 버튼 삭제.
- **인원수 1~3위 마크 (목록 + 지도 둘 다)**:
  - 관리 목록: 인원수 내림차순에서 상위 3개 앞에 🥇🥈🥉(그 외 순번 숫자).
  - 지도 버블: `makeBubbleOverlay`에 `rank` 파라미터 추가, `effSchoolSpots`/`effAptSpots`를 count 내림차순 정렬해 상위 3개에 우상단 `N위` 배지.
- **위치 보정(좌표/드래그)**: 목록 항목 클릭 → `startPlaceAdjust`가 드래그 가능한 kakao Marker 생성 + 지도 이동. 인라인 좌표 입력(`placeCoordStr`)과 핀 드래그가 동기화되고, `저장`(place-spots POST lat/lng) / `취소`. 기존 `여기로`의 `focus()`는 제거.

## 5. 정류장 목록 행 컴팩트화

- **문제**: 행 글자·여백이 과하게 큼(2줄, ~58px/행). 수정은 이제 팝업에서 되므로 행 자체는 압축 가능.
- **구현**: `renderCoordStopRow`를 1줄 버튼(~32px)로 교체 — `상태점 + 이름(12px) + 방향 등(파랑)·하(빨강) + 인원수 + ›`. 인라인 `수정/지정` 버튼·둘째 줄 제거(편집은 팝업의 위치이동/좌표/드래그로 동일 가능). 인원수용 `stopStudentCounts` useMemo 추가(등·하원 `student_id` Set으로 중복 제거 집계).

## 6. 뷰별 개수 요약 한 줄

- `전체/호차별/미설정` 토글 바로 아래에 현재 뷰 개수 표시:
  - 전체 → `전체 총 N개`
  - 호차별 + 호차 → `{호차} N개`
  - 호차별 + 호차 + 세션 → `{호차} · {세션} N개`
  - 미설정 → `미설정 N개`
- 검색어 필터 반영, 호차/세션 개수는 `bothDirGroups`(양방향 enrollment) 기준 집계.

## 검토 (review)

수행한 점검과 결과:

- ✅ **타입/빌드**: 각 단계 `tsc` 0, `next build` 0.
- ✅ **ref 충돌**: 신규 `stopEditHlRef`가 기존 `highlightMarkerRef`와 중복 선언되어 빌드 에러 → 별도 이름으로 분리 해결. 두 하이라이트는 용도·수명이 달라 독립.
- ✅ **z-index 계층**: 맵패널/FAB(1000) < 리모컨(1100) < 정류장 수정 팝업(8000) < 정류장추가/탑승자추가 모달(9001~9003). 하위 모달이 팝업 위에 정상 노출.
- ✅ **기능 보존**: 행에서 뺀 `수정/지정`(startAdjust)은 stopPopup(다른 흐름)에서 여전히 사용 → 미사용/유실 아님. 팝업 내 위치이동으로 동일 편집 가능.
- ✅ **정렬 일관성**: 목록(메달)·지도 버블(N위) 모두 count 내림차순 기준이라 상위 3위 일치.

### 발견·수정한 문제

- 🐞→✅ **위치 보정 드래그 핀 잔존**: `placeAdjust` 진행 중 관리 패널을 닫거나(✕) 학교↔아파트를 전환하면 인라인 에디터는 사라지지만 지도의 드래그 핀(`placeMarkerRef`)과 상태가 정리되지 않아 핀이 남고 상태가 묶일 수 있었음.
  - **수정**: `spotManage`가 바뀔 때(`!== placeAdjust.kind`, null 포함) `cancelPlaceAdjust()`를 호출하는 effect 추가 → 패널 닫힘/종류 전환 시 핀·상태 자동 정리.

### 남은 경미 사항 (현재 미처리, 영향 낮음)

- 좌표가 없는(`미설정`) 정류장은 수정 팝업을 열어도 강조 핀이 안 뜸(좌표가 없으니 위치 부재). 팝업의 검색/직접입력/위치이동으로 좌표를 잡으면 정상 표시. 필요 시 "미설정 시 지도 중심에 임시 핀" 추가 검토.
- 좌표 직접 입력 중 부분 입력(예: `37.`)에서 핀이 즉시 이동해 약간 튀는 느낌(parseFloat 즉시 반영). 영향 미미.
- `placeAdjust`/`expandedStop` 활성 상태에서 컴포넌트 언마운트 시 마커 정리 미보장(페이지 언마운트가 드물어 보류).
