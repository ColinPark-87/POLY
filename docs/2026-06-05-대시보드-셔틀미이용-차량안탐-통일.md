# 2026-06-05 메인 대시보드 — 셔틀 미이용(차량안탐) 표기 통일

대상: `/campus/dashboard` 호차별 탑승현황(BusCapacityCards). 백업 선행, 비파괴.

## 증상 (문의)
요일별 셔틀 배정에서 "셔틀 안 타는 학생"을 "배정 없음"으로 두면, **어떤 학생은
대시보드에 '차량안탐'으로 뜨고 어떤 학생은 아무것도 안 뜸**(불일치).

## 원인
요일별 호차 드롭다운(`class-roster/page.tsx`)은 `없음`(빈값) + **버스 목록**으로 구성되는데,
대치 캠퍼스엔 **"차량안탐"이 실제 버스(campus_buses)로 등록**돼 드롭다운에 함께 뜬다.
같은 "셔틀 안 탐"을 두 값으로 저장:
- **"없음"** 선택 → `arr/dep_schedule[요일]` = `""`(빈값) → 대시보드 집계 제외(아무것도 안 뜸)
- **"차량안탐"** 버스 선택 → `"차량안탐"` → 대시보드 '차량안탐' 카드에 집계
대시보드(`dashboard/route.ts`)는 스케줄의 호차값으로만 카드를 만들어 표기가 갈렸다.

## 결정 (사용자 선택)
**빈값(없음)도 "차량안탐(미이용)"으로 함께 집계해 일관 표시.**

## 구현
- **신규 순수 함수** `lib/campus-dashboard-buses.ts` `computeNoShuttleByGroup()`
  - 그룹별 **운행요일**(등원∪하원 실탑승이 있는 요일)에 한해, **실탑승이 없는 학생**을
    "차량안탐"으로 방향별 집계.
  - **복수 enrollment 안전**: 학생 단위로 실탑승 요일을 먼저 모아, 다른 반에서 그 요일
    실제로 타면 미이용으로 세지 않음.
  - **요일제 반 안전**: 2일반(화목)·3일반(월수금)은 그 그룹이 운행하지 않는 요일은 미집계.
  - 학생|요일 단위 중복 제거. `''`·`_loc` 접미 키는 실탑승으로 보지 않음.
- **`dashboard/route.ts`**: 실 탑승 집계 루프 뒤에 위 함수 결과를 `arrByGroup`/`depByGroup`의
  "차량안탐" 버킷에 **`+=` 합산**(명시적 '차량안탐' 버스 배정분은 실탑승으로 이미 집계되어
  중복되지 않음). `arrTotal`/`depTotal`(실 셔틀 적재량)에는 미포함.
- **`dashboard/page.tsx` BusCapacityCards**: campus_buses에 없어도 "차량안탐" **합성 컬럼**을
  맨 뒤에 렌더(라벨 '안탐', 회색). 정원 초과/주의(🚨⚠️) 경고에서는 제외.

## ⚠️ 알아둘 점 (의미상 한계)
빈값은 현재 **"안 탐"과 "아직 미입력"을 구분하지 못함** → 둘 다 '차량안탐(미이용)'으로 집계됨.
사용자 결정(빈값=안탐)에 따른 것. 만약 "미입력"을 분리하고 싶으면 입력 단계에서
'셔틀 안 탐'을 명시 값으로 저장하는 추가 작업 필요(후속 가능).
또한 본 통일은 **주간(스케줄) 기준 호차 현황**에 적용. '오늘' 기준 별도 집계가 필요하면 후속.
